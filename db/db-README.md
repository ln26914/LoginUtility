# Database

This folder will contain the files necessary to interact with a database.

During implementation and testing, the databases will reside in this folder.
During deployment, databases will be moved out of this folder and into a cloud database. This is referred to as 'Migration'.

## Things that go here

Database files (pre-Migration)

API keys (store securely and hide from prying eyes)

Interfaces to cloud databases

## Things that do not go here

Database files post-migration

Scripts (except those that interface with source code layer)

Webpage elements of any kind
