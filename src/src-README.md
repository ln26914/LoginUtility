# Source Code

This folder contains the scripts that act in the middle, connecting the web interface with the server layer.

If it's a script that runs, it goes into this folder.

Filepaths (particularly to databases) should not be hard-coded in order to make database migration run more smoothly.

## Things that go here:

Event Handlers

Database API calls

Credential validation

Functions

Miscellaneous code

## Things that don't go here:

Database API keys

HTML Webpages

Images to embed into webpages

CSS
